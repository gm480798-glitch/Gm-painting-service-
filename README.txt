GM Painting Service - upload guide
1. In this folder run:  npx wrangler deploy
   NOTE: wrangler.jsonc worker name is "gm-painting-service-new". If your Cloudflare Worker has a different name, change only that one line.
2. Static site only. Sitemap (sitemap.xml) and robots.txt are included.
3. After deploy: open /sitemap.xml and submit it in Google Search Console.
4. Test once: rental flow, Rs.35 booking form, QR scan on phone, WhatsApp buttons.
