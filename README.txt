GM Painting Service - upload guide
1. In this folder run:  npx wrangler deploy
   (Worker name in wrangler.jsonc = gmpaintingservice. If your Cloudflare Worker has a different name, change only that one line.)
2. Static site only - no worker.js needed. SEO pages, sitemap.xml and robots.txt are included.
3. After deploy: open /sitemap.xml and submit it in Google Search Console.
4. Test once: rental flow, ₹35 booking form, QR scan on phone.
